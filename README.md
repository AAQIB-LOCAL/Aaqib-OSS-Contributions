This README deliberately does **not** count personal, internal, or organization-owned work as external OSS. Those PRs are still part of the full GitHub contribution history and were considered during the namespace audit.

### Fork handling

Fork-based work is not double-counted when the corresponding upstream PR is present. For example, a PR submitted from `Aaqibhafeezkhan/<repo>` and merged into an upstream repository is recorded once against the upstream repository.

### Namespace handling

The audit distinguishes repository ownership from contribution authorship. A repository appearing under a personal fork does not become an external OSS contribution merely because the fork owner differs from the upstream maintainer. The upstream repository and merged PR are the canonical record.
